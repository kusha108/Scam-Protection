🛡️ Scam Protection with AI

An AI-powered web application that detects and classifies suspicious messages, emails, and text content as Scam or Safe using Machine Learning.

🚀 Live Demo
🔗 https://scamdetectionss.netlify.app/

📌 Project Overview
Scam Protection with AI is a full-stack web application designed to protect users from fraudulent messages and phishing attempts.
The system analyzes text using an AI model and provides instant classification results.
It helps users:
Detect scam messages
Identify phishing content
Stay protected from online fraud

🧠 Features
🔍 Real-time scam detection
🤖 AI-powered text classification
📧 Email & message analysis
⚡ Fast prediction response
🌐 Fully responsive UI
🔐 Secure backend API
